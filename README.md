# KMA FILMS Frontend

Minimalistic frontend for movie catalog project.  
Demo site for browsing, searching, adding, and deleting movies.

## Features
- List movies with search and genre filter
- Add, view, and delete movies
- Mark favorites (via API)
- Responsive Netflix-style UI

## How to run
1. Clone the repo:
git clone https://github.com/le1zyyx/kma_films_frontend.git
cd kma_films_frontend


2. Start local web server:
python3 -m http.server 5500


3. Open [http://127.0.0.1:5500](http://127.0.0.1:5500) in your browser

**API Backend required:**  
Connects to Django REST API at [http://127.0.0.1:8000](http://127.0.0.1:8000)
